Política de Privacidad

Mathi JR es una aplicación para Discord con funciones de administración, moderación, tickets, economía virtual, automatización e inteligencia artificial. Esta política explica qué información puede procesar según las funciones que se utilicen.

Fecha de entrada en vigor: 7 de noviembre de 2026

1. Responsable y contacto

El proyecto se presenta como Mathi JR. Para consultas de privacidad, solicitudes de acceso, rectificación o eliminación, escribe a MathiJRdeveloper@gmail.com. En el mensaje puedes incluir tu identificador de usuario de Discord y el servidor relacionado, pero no envíes contraseñas ni tokens.

2. Información que podemos tratar

Según las funciones activadas por el servidor y las interacciones que realices, Mathi JR puede tratar:

  • Identificadores de Discord: ID de usuario, ID de servidor, ID de canal e información pública necesaria para ejecutar comandos y gestionar permisos.
  • Configuración y actividad del bot: ajustes del servidor, uso de comandos, puntuaciones, niveles, XP, saldos y recompensas de economía virtual.
  • Moderación y tickets: motivos de advertencias, IDs de moderadores, estado de tickets y mensajes o archivos que envíes mediante las funciones de atención.
  • Contenido enviado a IA: preguntas, respuestas y, cuando se utilice la función correspondiente, imágenes, archivos o contenido de voz. Algunas funciones pueden mantener un historial de solicitudes y respuestas asociado al usuario y al servidor.
  • Acceso al dashboard: identificadores de sesión y datos de autenticación de Discord necesarios para mostrar las opciones de administración autorizadas.
  • Datos técnicos: registros necesarios para identificar errores, prevenir abuso y mantener el servicio, conforme a lo que generen la aplicación y el proveedor de alojamiento.

3. Para qué usamos la información

Utilizamos estos datos para responder a comandos, guardar configuraciones, aplicar reglas de moderación, gestionar solicitudes y tickets, ejecutar automatizaciones, conservar progreso virtual, ofrecer funciones de IA, autenticar el dashboard y prevenir usos indebidos.

4. Proveedores y transferencias

Mathi JR utiliza la plataforma Discord y servicios de alojamiento, entre ellos Railway. Si el administrador habilita funciones externas de IA, la información necesaria para completar una solicitud puede enviarse al proveedor configurado, que puede incluir servicios como Google Gemini, Groq, OpenRouter, DeepSeek, OpenAI, ElevenLabs o Stability AI. No todos estos proveedores están necesariamente activos al mismo tiempo. Su tratamiento queda sujeto también a las respectivas condiciones y políticas de privacidad.

Estos proveedores pueden procesar información fuera de tu país de residencia. Los datos solo deberían compartirse cuando resulte necesario para la función utilizada o por una obligación legítima o legal aplicable.

5. Conservación

Los registros operativos, las configuraciones, los datos de economía virtual y ciertos historiales pueden permanecer almacenados mientras se necesiten para el funcionamiento de las funciones activadas. La conservación varía según el tipo de dato y la configuración del servidor; no se dispone de un plazo único de eliminación automática para todos los registros. Los datos pueden eliminarse mediante herramientas administrativas cuando existan y a través de solicitudes al contacto indicado, sujeto a obligaciones legales o razones de seguridad justificadas.

6. Acceso, rectificación y eliminación

Para consultar o solicitar la corrección o eliminación de datos asociados a tu usuario de Discord, escribe a MathiJRdeveloper@gmail.com. Indica tu ID de usuario y, si procede, el ID del servidor y el tipo de dato. Podremos pedir información razonable para comprobar que la solicitud corresponde a la persona autorizada. Se revisará cada petición y se responderá conforme a la legislación aplicable. La eliminación de ciertos datos puede desactivar funciones como la economía o el historial.

Si tu solicitud afecta a mensajes o contenidos almacenados directamente en servidores de Discord, también puede ser necesario contactar con los administradores de esos servidores o usar las herramientas de Discord.

7. Seguridad

Se aplican medidas técnicas de control de acceso, permisos y administración para proteger los datos. Ningún servicio conectado a internet puede garantizar seguridad absoluta. Los administradores de servidores son responsables de conceder permisos adecuados y configurar correctamente las funciones del bot.

8. Uso por menores de edad

Mathi JR debe utilizarse respetando los requisitos mínimos de edad de Discord y las leyes del lugar donde viva cada usuario. No debe utilizarse para solicitar intencionadamente información sensible a menores.

9. Cookies y sesiones

El dashboard puede utilizar cookies o identificadores de sesión necesarios para iniciar sesión, proteger formularios y conservar la autenticación. Esta página informativa no contiene publicidad ni sistemas de seguimiento propios.

10. Actualizaciones y contacto

Esta política puede actualizarse si cambian las funciones, proveedores o prácticas de tratamiento. La versión vigente estará disponible en esta página. Contacto: MathiJRdeveloper@gmail.com.
